Що таке побутова хімія

Побутова хімія включає різноманітні засоби, які використовуються для прибирання та догляду за поверхнями в будинку. До них належать засоби для скла, підлоги, кухні, ванної кімнати та інших поверхонь.

Основні види миючих засобів

  • засоби для миття скла;
  • засоби для кухні;
  • засоби для ванної кімнати;
  • засоби для підлоги;
  • універсальні миючі засоби.

Як обрати мийний засіб

Під час вибору засобу необхідно враховувати матеріал поверхні, призначення продукту та рекомендації виробника. Також варто звертати увагу на спосіб використання та необхідні заходи безпеки.

Для очищення скла можна використовувати спеціальні засоби для миття вікон.

Детальні рекомендації щодо очищення вікон наведені на сторінці «Як правильно очистити вікна».
